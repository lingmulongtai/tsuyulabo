# Vivarium assets

`studio.hdr` is an original, procedurally generated HDR studio light environment,
created for this project. Its source is `src/components/vivarium/generate-environment.mjs`.
It contains no photograph or third-party imagery. Dedicated to the public domain
under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

The fallback WebP images are renders of this project's procedural Three.js scene,
not photographs or externally sourced models. All geometry, texture patterns and
materials are implemented in `src/components/vivarium/`.
