# ゲームルール仕様（アルファ版）

サーバー（`services/api/src/tsuyulabo_api/domain/`）が正。クライアントは表示のために同じ式を持ってよいが、結果は必ずサーバーの返り値を使う。

数値はすべて `domain/constants.py` に集約し、ここと一致させる。

## 1. 時間

- タイムゾーン: `Asia/Tokyo` 固定（アルファ）。
- **1日の区切りは 04:00**（04:00〜翌03:59 が「その日」）。
- 時間帯（slot）:
  - `morning` 04:00〜11:59
  - `noon` 12:00〜17:59
  - `night` 18:00〜03:59（日付をまたぐ。03:59 までは前日の night）
- **ゲーム時刻 = サーバー時刻 + ユーザーごとの dev オフセット**。オフセットは開発環境（`TSUYU_DEV_TOOLS=1`）でだけ変更できる。端末の時計は一切使わない。
- 経過による変化（ステータスの減少、採集）は、読み出し時にまとめて計算する（遅延評価）。24時間シミュレーションは回さない。

## 2. 研究週（1週間の育成）

- 週は**ユーザーが卵を受け取った日を 1日目**として 7日間（アルファでは暦の月曜にそろえない）。表示上の曜日ラベルは 1日目=月 … 7日目=日。
- 卵を受け取れるのは、進行中の週がないとき（初回、または前の週の羽化後）。

| 日 | 曜日 | 段階 `stage` | 主なイベント |
| --- | --- | --- | --- |
| 1 | 月 | `egg`（夜の slot 開始で `larva1` にふ化） | 温度あわせ（必須）、寝床づくり（=ごはん） |
| 2 | 火 | `larva1` | ごはん×3、そうじ、しつけ解放 |
| 3 | 水 | `larva2`（2日目→3日目の境で脱皮） | ごはん×3、そうじ、しつけ |
| 4 | 木 | `larva3` | 食べざかり: ごはんの成長ポイント ×1.5 |
| 5 | 金 | `wandering` | 夜にさなぎの場所えらび（必須） |
| 6 | 土 | `pupa` | 温度あわせ（必須）、見守り。羽化の予兆 |
| 7 | 日 | `pupa`（夜の slot で羽化可能） | 大成功が出やすい日。夜に研究発表会 → 羽化 |

- 段階は「研究日」と slot から決まる純関数 `stage_at(week_start, game_now)`。
- 7日目の night 以降は `ready_to_eclose`。羽化するまで週は終わらない（羽化を後回しにしても不利にならない）。

## 3. お世話の回数制限

| 行動 | 回数 | 使える日 |
| --- | --- | --- |
| ごはんづくり `meal` | 各 slot 1回（1日3回） | 1〜7日目 |
| しつけ `training` | 1日3回（slot 問わず） | 2〜7日目 |
| そうじ `cleaning` | 1日1回 | 2〜5日目 |
| 温度あわせ `temperature` | 1日1回 | 1日目・6日目 |
| さなぎの場所えらび `pupation_site` | 1回 | 5日目の night |
| おやすみ `sleep` / おはよう `wake` | 1日1回ずつ | 毎日 |

## 4. ステータス（幼虫のあいだだけ変化）

値はすべて 0〜100 の整数に丸めて返す（内部は float）。

- `hunger`（おなか）: ごはんで +40（大成功で +60）。1時間に -12.5（8時間で空）。
- `cleanliness`（きれい）: そうじで `score`（0〜100）に**上書き**。1時間に -4。
- `mood`（ごきげん）: `round(0.6 * hunger + 0.4 * cleanliness)`。表示用ラベル: 70以上「ごきげん」、40以上「ふつう」、それ未満「しょんぼり」。
- 卵とさなぎの間は減少しない（値は凍結）。ふ化時に hunger=60, cleanliness=100 から開始。

## 5. ケアミス

日（04:00 区切り）が終わったとき、または読み出し時に過ぎた分をまとめて判定する。

- 2〜5日目: 各 slot でごはんをしなかった → slot ごとに +1
- 2〜5日目: その日にそうじをしなかった → +1
- 1日目・6日目: 温度あわせをしなかった → +1
- 5日目: さなぎの場所えらびをしなかった → +1（自動で真ん中の候補が選ばれる）
- 幼虫のあいだに `hunger` が 0 のまま 3時間以上続いた → 1回だけ +1

## 6. 研究発表会（7日目の night）

```
points = meal_points + training_points + care_points - care_miss * 500
meal_points     = Σ(ごはんの score) + 大成功の回数 * 1000
training_points = Σ(★の数) * 400 + ひらめきの回数 * 300
care_points     = Σ(そうじの score) * 5 + Σ(温度あわせの score) * 5 + 場所えらびの当たり * 1000
```

| ランク `rank` | 条件 | 色 |
| --- | --- | --- |
| `normal` ノーマル | 〜5,999 | 白 |
| `silver` シルバー | 6,000〜 | 青 |
| `gold` ゴールド | 11,000〜 | 金 |
| `rainbow` にじ | 16,000〜 | 虹 |

報酬: しずく = `floor(points / 6)`、研究ポイント = `floor(points / 40)`。台帳に記録する。

## 7. 羽化

羽化はサーバーが乱数で決める（シードはサーバーだけが知る）。

### 予兆の段階（tier）の確率（%）

| rank | 白 (tier 0) | 青 (1) | 金 (2) | 虹 (3) |
| --- | --- | --- | --- | --- |
| normal | 72 | 22 | 5.5 | 0.5 |
| silver | 60 | 30 | 9 | 1 |
| gold | 40 | 38 | 18 | 4 |
| rainbow | 20 | 40 | 30 | 10 |

- 温度あわせの平均 score が 80 以上なら、白から 3 ポイントを青へ移す。
- 場所えらびが当たりなら、白から 2 ポイントを金へ移す。
- 確率表はすべて API で公開する（`GET /v1/odds`）。

### tier から決まるもの

| tier | 素質 ★ | 系統 |
| --- | --- | --- |
| 0 白 | 1 または 2（半々） | 野生型 |
| 1 青 | 3 | 野生型 |
| 2 金 | 4 | 野生型 |
| 3 虹 | 5 | 突然変異: `white`, `yellow`, `ebony`, `curly`, `vestigial` から等確率 |

- 「ときどき外れる予兆」: 演出用に `omen_sequence`（例: 白→青→金 で止まる）を返す。最終 tier まで上がって止まる。tier 2 以上のとき 30% で、一度 tier+1 の色を一瞬見せてから戻る「フェイク」を入れてよい（演出のみ。結果は変わらない）。
- 性別: 50%/50%（`m` / `f`）。
- 生まれつきの特性: 下の 8 種から重複なしで 2 つ。

| id | 表示名 | 脳パラメータへの効き方（brain.md 参照） |
| --- | --- | --- |
| `right_turner` | 右曲がりぐせ | 左右の旋回ニューロンの重みの非対称 +15% |
| `left_turner` | 左曲がりぐせ | 同 -15%（`right_turner` と同時には出ない） |
| `light_lover` | 光が大好き | 光受容体→前進のゲイン +30% |
| `keen_nose` | 匂いにするどい | ORN のゲイン +25% |
| `brave` | 度胸がある | DNp01 のしきい値 +20%（逃げにくい） |
| `wanderer` | よく歩く | 歩行 DN の自発発火 +30% |
| `easygoing` | のんびりや | 歩行 DN の自発発火 -30%（`wanderer` と同時には出ない） |
| `glutton` | 食いしんぼう | 糖 GRN→MN9 のゲイン +25% |

## 8. 成虫

- 羽化した個体は飼育室に残り続ける。飼育室の枠はアルファでは 30。
- レベル 1 から開始。**レベル上限**: ★1=20, ★2=30, ★3=40, ★4=50, ★5=60。
- レベルアップ費用（しずく）: レベル n → n+1 で `20 * n`。採集の経験値でも上がる（アイテム 1 個 = 1 exp、必要 exp = `10 * n`）。
- **サブスキル**: レベル 10・25・50 で 1 つずつ解放。中身は解放時にサーバーが抽選して固定。

| id | 表示名 | 効果 |
| --- | --- | --- |
| `gather_s` | 採集量アップS | 採集量 +8% |
| `gather_m` | 採集量アップM | 採集量 +16% |
| `great_up` | 大成功率アップ | チームにいる間、ごはんの大成功率 +2%（加算、チーム全体で最大 +10%） |
| `drop_bonus` | しずくボーナス | 採集のしずく +20% |
| `bag_up` | 材料袋アップ | 袋の上限 +10 |
| `energy_up` | げんき回復アップ | 睡眠によるげんき回復 +20% |
| `rp_up` | 研究ポイントアップ | 発表会の研究ポイント +5% |

## 9. 研究チームと採集

- チームは最大 5 匹。出し入れは自由（入れ替えた時点までの採集は確定させる）。
- 1匹あたり 1時間の採集数 = `(1.5 + 0.1 * level) * energy_factor * (1 + gather_bonus)`
  - `energy_factor` = げんき 60以上 1.0、20以上 0.6、それ未満 0.2
  - げんき（energy）は 1時間に -5。おやすみ→おはようの睡眠で `min(100, 睡眠時間[h] * 15 * (1 + energy_up))` 回復。
- 袋の上限: 1匹 30 個（`bag_up` で +10）。上限に達したら止まる。
- 材料の種類: `banana`, `apple`, `grape`, `yeast`, `agar`。基本の重みは各 1.0。しつけで**好き**になった匂いの材料は重み +2.0 × 学習の強さ（0〜1）。
- 1時間あたりしずく: `2 + 0.2 * level`（`drop_bonus` で +20%）。
- まれにレアドロップ（1個ごとに 1%）: `royal_jelly`（げんき +30 のアイテム）。
- 集めたものは `POST /v1/team/collect` で受け取る（それまでは袋にたまる）。

## 10. 睡眠（おやすみ / おはよう）

- `sleep` は night slot でだけ押せる。`wake` は morning slot でだけ押せる。
- 睡眠時間 = wake 時刻 − sleep 時刻（最大 10 時間で打ち切り）。
- 睡眠ボーナス（しずく）= `floor(min(睡眠時間, 8) * 25)`。朝のシオリのメモに表示。
- チームのげんき回復（上記）。

## 11. 経済（アルファ）

- 通貨: `shizuku`（しずく、無料）、`research_points`（研究ポイント）、`kohaku`（こはく、有料。アルファでは付与も使用もしない。台帳の型だけ用意）。
- 材料はインベントリ（数量）で持つ。
- 通貨の増減はすべて**複式の台帳**（ledger）に記録。残高は台帳から導出できること。
- 初期付与: しずく 300。

## 12. フレンド

- 各ユーザーに 8 文字のフレンドコード（英大文字+数字、紛らわしい文字 `0 O 1 I` を除く）。
- フレンドは最大 50 人。申請なしの相互登録（コードを入れたら両方に追加）。
- いいね: 相手ごとに 1日 1回。
- おすそわけ: 1日 1回（全体で）、自分の材料を 1 種類 5 個まで送る。送った側に研究ポイント +10。
- 飼育室をのぞく: 相手の成虫一覧、チーム、今週育てている子の段階とステータス（数値は丸めて見せる）。
