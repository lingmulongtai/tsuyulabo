# なわばりずもう（Phase 3）

プレイヤーのオス成虫とフレンドのオス成虫、または週替わりの「おうちの子」が非同期で対戦する。挑戦時に双方の脳状態・特性・レベルを固定し、サーバーが seed を選んでその場で計算する。購入物、通貨残高、見た目は勝敗の入力にしない。リプレイは各 tick の行動と位置を保存し、あとから再生できる。相手の脳状態は公開しない。

半径 4 の円形マットの中心に餌場がある。両者は左右の端から始まり、最大 30 tick。各 tick に脳ファサードが `approach`, `lunge`, `wing_threat`, `hold`, `retreat` の確率を出す。接近・後退は位置を動かし、隣接時の lunge は相手を押す。wing threat は次の押しを強める。マット外に出るか、3 回後退したら負け。時間切れは中心への近さで決め、同距離は seed で決める。`brave` は逃避回路のしきい値を上げ、`wanderer` は歩行ゲインを上げる。レベルのスタミナ加算は最大 10% とし、消耗しても行動不能にはしない。

1 日 3 戦まで。日付はゲーム時計の日本時間の日境界で区切る。勝利で 10 しずく、敗北で 3 しずくを台帳に記録する。連勝は直近の結果を新しい順にたどって表示する。フレンドでなくなった相手との過去のリプレイは本人だけが見られる。

**本物**: オスのショウジョウバエは餌やなわばりをめぐり、突進、翅を広げた威嚇、前脚での押し合いなどを見せる。オクトパミンは攻撃行動の調節に関わる。このゲームの押し合いと脳ファサードは観察をもとにした遊び用の簡略モデルで、実際の神経活動の再現ではない。

API: `GET /v1/sumo/challenges` は自分のオス、フレンドのオス、週替わりの家の相手、残り回数、連勝を返す。フレンドの脳状態と特性は公開しない。`POST /v1/sumo/bouts` は自分の成虫 ID と相手 ID（家は `house`）を受け、保存した結果とリプレイを返す。`GET /v1/sumo/bouts` は自分の履歴、`GET /v1/sumo/bouts/{id}` は自分の保存済みリプレイを返す。更新は共通の冪等性キーを必須とする。
