# ツユラボ v2 の方針（2026-10-12、オーナーの指示）

この文書が v2 の正。企画書 v0.2 や既存の仕様とぶつかったら、こちらを優先する。

## 1. ひとことで

**手のひらの小さな命を、本当に育てている。**
画面の向こうの飼育びんの中で、本物そっくりのショウジョウバエが、自分の脳で生きている。
卵から育て、ごはんを作り、しつけ、世代をつなぐ。研究ではなく、**飼育のゲーム**。

## 2. やめること

- **「研究」という枠組みをやめる。** 研究員・研究所・研究発表会・研究チーム・研究ポイント・研究◯日目・論文・実験の言葉を、
  画面から消す（内部の変数名や DB の列名は変えなくてよい）。データや ID を見せる画面、グラフ中心の画面もやめる。
- かわいいデフォルメ路線をやめる（AI の描く絵では質が上がらない）。**超リアル**に振る。
- 「AI に質問するチャット」を主役にしない。誰も使わない。

## 3. 見た目（デザインの正）

**マクロ写真の世界。** Three.js（`@react-three/fiber` + `drei` + `postprocessing`）で、飼育びんの中を実写のように描く。

- 主役は 3D の飼育びん。画面いっぱい、常に生きて動いている。UI はその上に薄く重ねるだけ。
- 光: 暖かい琥珀色のキーライト、横からの柔らかい補助光、ガラスの映り込みと屈折、結露のしずく。
- カメラ: マクロレンズ。浅い被写界深度（ピントの外はとろけるボケ）、指で回して寄れる。ピントは虫に合い続ける。
- 生き物の質感:
  - 成虫: 赤い複眼（六角の個眼が寄ると見える）、薄膜干渉で虹色に光る翅、体の剛毛、黄褐色の胴、腹の縞。
  - 幼虫: 半透明の白い体、中の器官が透ける（サブサーフェス散乱）、黒い口鉤、体節がうねって進む。
  - 卵: 白く細長く、2 本の呼吸糸。さなぎ: 琥珀色から黒に変わっていく殻。
- 飼育びん: 透明なガラス（またはプラ）、底に黄色いコーンミールの餌（湿り、表面のイースト、幼虫の掘った跡）、綿栓。
- 色: 自然光の色そのまま。UI の色はガラスに合う中間色（墨、生成り、琥珀）と、注意だけに使う 1 色。
- UI: 細い線、半透明の板（すりガラス）、小さな文字。アイコンは線画。演出は「実物の手触り」（ガラスを拭く、ダイヤルを回す、
  ピンセットで置く）。ポップな色、丸ゴシックの大見出し、キャラ絵の多用はやめる。
- 動き: 虫の動きは脳モデルの出力から作る（歩く、止まる、毛づくろい、餌を食べる、飛び立つ、光や匂いに寄る/逃げる）。
  決まったループ再生ではなく、毎回ちがう。
- 速さ: スマホで 60fps を目標、重い端末は画質を自動で下げる（ボケと影を切る）。WebGL がない端末は静止画にする。

## 4. ゲームとしての核

**自分の手で環境を整え、その結果が目の前の命に出る。** すべての操作は、飼育びんの中の目に見える変化につながる。

| 操作 | びんの中で起きること | 効くもの |
| --- | --- | --- |
| ごはん（ブロックパズル） | 自分で配合した餌がびんの底に入る。色・水気・イーストの量が見える。幼虫が潜って食べる | 成長の速さ、成虫の大きさ、体力 |
| しつけ（回路パズル） | 匂いとごほうび/苦いものを結びつける練習。次から、その匂いに寄る/避ける姿が見える | 脳のつながり（好き・苦手）、性格 |
| そうじ | 曇ったガラス、カビ、増えすぎたダニを、指で拭く・取る | 病気、元気、寿命 |
| 温度・湿度 | ダイヤルを回すと、虫の動きの速さや結露が変わる | 成長の速さ、体内時計 |
| さなぎの場所 | 幼虫がガラスを登る。どこで止まらせるか選ぶ | 羽化の成功、翅の形 |

- **時間は本物に近く流れる**（1 週間で卵 → 成虫）。放っておくと餌が乾き、カビが出て、虫は弱る。毎日見に来たくなる理由。
- **個体はみんなちがう。** 遺伝（目の色・翅・体色、伴性遺伝、致死）、生まれつきの脳の個性、育て方でついた癖。
  名前・性格・好き嫌いが、行動として見える。
- **奥深さ**: 交配で系統をつなぎ、珍しい形質を固定する。複数のびん（コロニー）を並べて世話する。迷路レース・なわばりずもうは
  その子の脳で戦う。図鑑は「集めた系統と性格」。
- **週の終わり**: 「羽化の日」。研究発表会ではなく、育ちの良さが、その子の姿（大きさ、翅のつや、元気さ）と称号になる。

## 5. AI の使い方（意味のあるところだけ）

1. **虫そのものが AI。** 脳モデル（本物の配線）が行動を決める。育て方で脳が変わり、性格になる。これがこのゲームの核で、
   いちばん見せるべき AI。数値ではなく、行動と「性格のことば」で見せる。
2. **観察日記を自動で書く。** その日の出来事（初めて飛んだ、バナナの匂いに寄った、カビを避けた）を拾い、
   短い日記と 3D のスナップショットにする。あとで見返せる、友だちに見せられる。自作のローカル LLM で書く。
3. **困ったときだけ、そっと教える。** 暑すぎる、餌が乾いた、カビが出た、を虫の様子から読み取って一言。チャットではない。
4. **虫をタップして「どうして？」** その瞬間の行動の理由を、その子の脳と育ちから短く答える（今のシオリの仕組みを使う）。

シオリは「研究員」ではなく、飼育を手伝う相棒（名前は残す）。画面に常駐させない。
