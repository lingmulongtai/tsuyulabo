# ツユラボ v2 の表示用語

`vision-v2.md` を正とする。手のひらの小さな命を育てるゲームとして、温かく、短く、具体的に書く。呼びかけは必要なときだけ使う。

| 研究週 | この子の一週間 |

## 説明の約束

- ごはんを配合してびんの底へ入れる。食べ方と育ちに変化が出る。
- 匂いとごほうびを結びつけるしつけで、好き・苦手が育つ。
- そうじでガラスと餌のまわりを清潔に保ち、病気を防ぐ。
- 温度と湿度で、動きや育つ速さが変わる。
- さなぎになる場所を選び、羽化を見守る。
- 同じ世話でも育ちはそれぞれ違う。コロニーで親から子へ系統をつなぐ。

数値は操作に必要な残り時間、温度、パズル得点などに限って主表示に使う。能力値や配線図は補足として開ける場所へ移し、最初にその子の様子を短い言葉で伝える。シオリの根拠は隠さず、小さな開閉表示に置く。好みやコピーの試行回数の報告は数値から短い言葉に読み替え、元の説明を根拠の中に残す。未対応の数値報告は補足に置き、個体の状態を推測で作らない。

## 意図して保持するもの

- 内部識別子、URL、API フィールド、DB 列、マイグレーション、得点計算の契約は変更しない。
- `services/shiori` の `SYSTEM_PROMPT`、MockProvider のテンプレート、学習・評価データは W17 の担当。旧語が返っても Web の表示境界で置き換え、元の回答と根拠 ID は保持する。
- 過去の企画書、開発計画、仕様の履歴、コードの技術コメントはプレイヤー向け画面ではないため旧語を残す。
- `apps/web/src/components/vivarium/` と `apps/web/src/app/vivarium/` は W14 の担当。W15 は変更しない。
- ツユラボという固有名は継続する。Android の表示名は「ツユラボ」、内部識別子は既存のまま。
- プレイヤーが入力した名前・称号・質問と、既存の初期プロフィールは保存値として保持する。旧語を含むユーザー入力と、表示境界の翻訳辞書・回帰テストの旧語は意図的な例外。

W15 は UI の材料と説明を整える。パズルの結果が 3D のびんに反映される統合は W16、日記と困ったときの相棒は W17。未統合の操作を実装済みとして案内しない。
