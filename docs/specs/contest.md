# 見た目コンテスト

装飾は見た目だけを変える。育成、研究、投票数、同票順位に効果を与えない。購入品は実装されていないが、所持品には `source` (`starter` / `presentation` / `research` / `paid`) を保存する。`paid` の品はコンテストの応募に使えない。

## 装飾と獲得

| 品 | 種類 | 無料の獲得条件 |
| --- | --- | --- |
| 透明ビン、若葉の背景 | ビン、背景 | 初期所持 |
| 雨粒ビン、しずくのリボン | ビン、頭飾り | 発表会シルバー以上 |
| 虹の背景 | 背景 | 発表会にじ |
| バナナの飾り | 床飾り | 研究ランク 2 |
| 小さな花 | 床飾り | 研究ランク 6 |
| 葉っぱの帽子 | 頭飾り | 研究ランク 11 |

同じ品は一度だけ獲得する。床飾りは左右の固定スロットに置き、その他の種類は各 1 個を選ぶ。外すこともできる。所持品は取得時の出所を保持する。応募時は装備をスナップショット化し、以後の編集は応募を変えない。

## 週と投票

日本時間の ISO 週ごとにテーマを巡回する（「梅雨の研究所」「バナナ祭り」「緑の実験室」「虹の飼育室」）。月曜 00:00 から金曜 23:59:59 まで応募、土曜 00:00 から日曜 23:59:59 まで投票、翌月曜から結果を公開する。応募は週に 1 人 1 件、所有する成虫 1 匹を添える。応募時の装飾はすべて本人が所有する無料品でなければならない。

各プレイヤーは投票期間中、応募したフレンドへ最大 3 票を投じる。自分へ投票できず、同じ応募へは 1 票だけ。投票後は取り消せない。結果は票数の降順、同票は応募時刻の早い順、なお同じなら応募 ID 順。応募した人に 5 しずく、終了後の上位 3 名に順に 30、20、10 しずく。結果閲覧時に未配布報酬を一度だけ配布する。結果には本人とフレンドの応募を表示し、投票数は投票終了後だけ表示する。

`GET /v1/decorations` はカタログ、所持品、レイアウトを返す。`PUT /v1/decorations/layout` は固定スロットの品 ID または null を受け取る。`GET /v1/contest/current` はテーマ、期間、本人の応募、閲覧可能なフレンドの応募、投票残数、投票済み応募 ID を返す。`POST /v1/contest/current/entry` は `adult_id` を送り、保存済みレイアウトを応募へ複写する。`POST /v1/contest/current/votes` は `entry_id` を送る。`GET /v1/contest/results` は直近終了週の順位を返す。すべての変更 API は `Idempotency-Key` を必須とする。
