# ツユラボ v0.1.0-alpha.1

Android 向けの初回アルファ版です。アプリから公開デモサイトを開き、育成画面などを試せます。通信エラー時には卵のオフライン画面を表示します。

## インストール

1. 下の `tsuyulabo-v0.1.0-alpha.1-debug.apk` を Android 端末にダウンロードします。
2. 端末の設定で、ダウンロードに使ったアプリに「不明なアプリのインストール」を許可します。
3. APK を開いてインストールします。インストール後は必要に応じて許可を戻してください。

この APK は **Android のデバッグ鍵で署名された検証用ビルド**です。正式なリリース署名版ではありません。

## 制限事項

- バックエンドはまだ公開されていません。現在はデモモードのみ利用できます。
- ゲーム本体はオンラインの公開サイトを読み込みます。オフラインではプレイできません。
- デバッグ署名版は将来の正式署名版へ上書き更新できません。その際はアンインストールが必要になる場合があります。
- iOS 版とストア配信はまだありません。
